## Source-use rules

- Official protocol and provider documentation governs adapter facts.
- Standards and regulator sources govern assurance interpretations.
- Provider marketing announcements establish availability claims only when corroborated by accessible technical documentation.
- Current support, network, API, and contract facts are reverified immediately before implementation and certification.
- Internal research and prior architecture documents are design inputs, never independent proof of current external behavior.
