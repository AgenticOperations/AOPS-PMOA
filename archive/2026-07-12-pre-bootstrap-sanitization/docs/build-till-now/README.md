Backlinks: [[10-Projects/Web3-Builds/agentOps/BUILD-PMOA/README]] | [[10-Projects/Web3-Builds/agentOps/PMOA-EVENT-PRD/42-build-execution-operating-model]]

This folder is the contributor-facing build history for `BUILD-PMOA`.

Use it when someone joins the project and needs to understand what has actually been built, why it was built, what tests prove it, and which issues were found while building it.

## Rule

Every completed section must add or update two files:

1. `section-<section-id>-<slug>.md`
   - what was built,
   - why it was built,
   - backend boundary,
   - frontend boundary,
   - files changed,
   - verification commands,
   - what remains for later sections.

2. `error_log_section-<section-id>-<slug>.md`
   - every meaningful error encountered,
   - cause,
   - fix,
   - status,
   - prevention note.

Do not bury implementation history only in chat or handoff. Handoff carries current state; this folder carries section build history.
